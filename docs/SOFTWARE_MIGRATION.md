# Target Computer Scoped Ecosystem Planning

## Goal

本项目是“家庭电脑高风险软件生态整理工具”，不是国产软件清理器，也不是开发电脑清理工具。

处理链：扫描 → 软件分类 → 保护名单过滤 → 目标软件分析 → 生成建议。

## Protection levels

- P0：系统保护，忽略
- P1：用户软件保护，忽略
- P2：正常软件，仅报告
- P3：可评估软件，人工审查
- P4：明确的高推广目标生态，可生成建议但仍需人工确认

办公、通讯、浏览器、输入法及专业生产力软件默认 P1。保护规则优先于目标生态规则，因此 360/2345 浏览器在没有“非主浏览器、明显不用、用户确认”等证据时仍会被忽略。

## Target binding

扫描时通过目标画像写入 `target_id`，替代建议继承该身份。规划器要求目标画像、软件画像和替代建议身份一致；缺失或不一致时硬失败，避免分析 A 电脑却对 B 电脑形成计划。

## Outputs

- `migration_plan.json`：只包含 P3/P4 的审查或推荐项
- `migration_report.json`：包含所有软件及其保护处置，用于审计

所有输出均为方案，不存在安装、卸载、删除、注册表写入、启动项或系统配置修改能力。
