# Task007：Windows维护执行器与后台组件清理系统

版本：V1.0

## 一、任务目标

在已有 Task001-006 基础上，实现真实客户电脑维护执行能力。

目标不是简单删除软件，而是：

- 保证用户需要的功能继续可用
- 替换明显低质量软件
- 清理著名流氓软件生态
- 清理后台推广组件
- 清理启动、服务、计划任务等“伸出来的手”

执行必须经过网页人工确认。

---

## 二、核心原则

禁止：

- AI直接执行系统操作
- 自动批量删除
- 绕过权限
- 删除用户数据
- 修改用户习惯设置

必须：

扫描 → 生成方案 → 人工确认 → 白名单执行 → 验证 → 报告

---

## 三、执行架构

```
Web控制台
 ↓
任务队列
 ↓
Agent
 ↓
Action Validator
 ↓
Safety Policy
 ↓
Executor
 ↓
Verification
 ↓
结果上传
```

# 七、输入法处理规则

不替换输入法。

不删除：

- 输入法主体
- 用户词库

只处理：

- 广告弹窗
- 新闻推荐
- 热点推荐
- 皮肤推广
- 游戏推广模块
- 推广助手

动作：

```
optimize_input_method
```

允许：

- 禁用推广启动项
- 禁用推广服务
- 禁用推广计划任务

禁止：

- 删除核心输入组件
- 删除用户词库
