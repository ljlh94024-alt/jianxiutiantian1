# Windows Clean Agent

# 项目设计理念扩展说明 V3.0

## 一、项目产生背景

普通家庭 Windows 电脑长期使用后，问题通常不是系统损坏，而是软件生态不断膨胀。

典型情况：

- 买电脑预装大量无用软件
- 下载软件时附带安装其他程序
- 卸载后留下服务和启动项
- 桌面出现壁纸、助手、资讯、推荐模块
- 开机后台越来越多
- 用户不知道哪些可以处理

因此本项目不是重新安装系统，而是在保留用户环境的基础上，进行一次授权后的电脑整理。

目标：

让普通用户获得一个：

- 干净
- 稳定
- 简单
- 易维护

的 Windows 环境。

---

# 二、项目不是传统优化软件

本项目不追求：

- 删除最多软件
- 修改最多系统参数
- 所谓一键加速
- 强制优化用户习惯

因为家庭电脑最重要的是：

功能不能丢，习惯不能破坏。

正确目标：

> 删除没有价值的东西，而不是删除所有东西。

---

# 三、核心思想：软件生态维护

现代软件不是一个exe文件。

一个软件生态可能包含：

```
主程序

更新程序

后台服务

启动项

计划任务

广告模块

推荐模块

桌面组件
```

用户看到的是一个软件，但后台可能运行多个组件。

因此维护重点不是软件名称，而是完整生态。

---

# 四、软件处理四大原则

## 1. 能替换，不直接删除

例如：

错误：

删除看图软件。

正确：

```
安装 ImageGlass
↓
测试图片打开
↓
删除旧看图软件
```

保证用户功能连续。

---

## 2. 不破坏用户数据

永远保护：

- 文件
- 图片
- 视频
- 浏览器收藏
- 登录状态
- 输入法词库

软件整理不是数据整理。

---

## 3. 不改变用户习惯

保护：

- 浏览器使用习惯
- 输入法习惯
- 办公软件环境

除非用户明确要求，否则不改变。

---

## 4. 规则优先于智能判断

AI可以帮助分析，但是不能直接决定执行。

最终执行必须经过固定规则。

---

# 五、重点清理对象理念

## 软件本体

处理：

- 明确无价值软件
- 有安全替代的软件

例如：

- 鲁大师
- 壁纸屏保软件
- 桌面美化软件

---

## 后台触手

重点：

### 服务

例如：

- 更新服务
- 推广服务
- 助手服务

### 启动项

例如：

- 开机助手
- 推荐程序
- 广告模块

### 计划任务

例如：

- 定时弹窗
- 自动推广

### 后台进程

例如：

- 新闻模块
- 资讯模块
- 推荐模块

---

# 七、输入法设计原则

输入法特殊处理。

原因：

- 使用频率高
- 用户依赖强
- 词库价值高

因此：

禁止：

- 删除输入法主体
- 删除词库
- 修改默认输入法

允许：

- 关闭广告
- 清理推广服务
- 禁止弹窗
- 清理推荐模块

目标：

保留输入能力，去除骚扰行为。

---

# 八、执行架构原则

完整流程：

```
扫描
↓
识别
↓
生成建议
↓
人工确认
↓
权限验证
↓
规则验证
↓
执行
↓
验证
↓
报告
```

任何一步失败必须停止。

---

# 九、为什么需要网页控制台

维护人员不应该直接操作客户电脑。

正确模式：

```
客户电脑 Agent

主动连接服务器

服务器展示状态

维护人员网页确认

Agent执行
```

优势：

- 可审计
- 可记录
- 可批量维护
- 降低误操作

---

# 十、AI的位置

AI不是执行者。

AI负责：

- 阅读报告
- 提供分析
- 辅助维护人员判断
- 生成说明

执行必须由：

固定代码 + 固定规则 + 人工授权

完成。

---

# 十一、长期目标

未来可以扩展：

- 更多软件规则
- 更多流氓组件识别
- 自动维护报告
- 多电脑管理
- 企业设备维护

但是核心不会改变：

> 人负责判断，程序负责执行，规则负责限制，日志负责证明。

---

# 十二、最终产品理念

一个好的家庭电脑维护工具，不应该让用户感觉电脑被接管。

应该像专业维修人员一样：

发现问题。

解释问题。

提出方案。

获得同意。

完成整理。

恢复一个用户真正需要的电脑环境。
