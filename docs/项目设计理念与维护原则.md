# Windows Clean Agent

# 项目设计理念与维护原则

版本：V1.0

---

# 一、项目定位

本项目不是杀毒软件，不是远程控制软件，不是自动优化软件。

目标：

> 为普通家庭 Windows 电脑提供一次性、安全、可审计的软件整理与维护能力。

核心场景：

维护人员通过网页查看客户电脑状态，人工确认后，让客户端执行固定、安全的维护任务。

---

# 二、核心设计理念

## 1. 人负责决定，程序负责执行

禁止：

- AI 自动删除软件
- 自动判断用户需求
- 自动修改重要系统设置

流程：

扫描 → 分析 → 网页展示 → 人工确认 → 执行 → 验证

---

## 2. 不追求“清空电脑”

目标不是删除最多软件。

目标：

- 保留用户需要的软件
- 删除明显无价值的软件
- 去除推广组件
- 恢复电脑干净状态

---

## 3. 软件与组件分离

很多问题不是软件主体，而是附属组件。

重点维护对象：

- 启动项
- 服务
- 计划任务
- 后台助手
- 广告模块
- 更新推广模块

不能只看软件列表。

---

# 三、维护优先级

## 第一优先：保护用户数据

永远禁止误处理：

- 用户文件
- 浏览器收藏夹
- 密码数据
- 用户词库

---

## 第二优先：保护常用软件

默认保护：

- WPS
- Microsoft Office
- 微信
- QQ
- 企业微信
- 钉钉
- 飞书
- 用户主要浏览器

---

## 第三优先：处理明显无价值软件

重点：

- 鲁大师
- 壁纸屏保类软件
- 桌面美化软件
- 2345推广生态
- 360非核心推广组件

---

# 四、软件处理原则

## 替换优先

例如：

2345看图王
↓
ImageGlass

360压缩
↓
7-Zip

广告播放器
↓
VLC

先保证功能，再删除旧软件。

---

# 五、输入法原则

输入法属于特殊软件。

禁止：

- 删除用户输入法主体
- 删除词库
- 修改默认输入法

允许：

- 清理推广弹窗
- 禁止广告启动项
- 清理推荐模块
- 关闭资讯组件

目标：

保留输入能力，减少骚扰。

---

# 六、安全执行原则

所有执行必须经过：

任务验证
↓
权限验证
↓
规则验证
↓
执行
↓
结果验证

禁止：

- 任意 Shell
- 任意命令执行
- 未授权删除
- 隐藏后台运行

---

# 七、规则设计原则

不要使用简单软件名称匹配。

必须结合：

- 软件名称
- 发布商
- 文件路径
- 服务名称
- 启动项
- 计划任务

降低误删除。

---

# 八、规则库方向

规则分为：

## protected

保护名单。

## replace

替代软件。

## remove

明确处理对象。

## component_behavior

后台组件行为规则。

---

# 九、后台组件重点

重点检查：

- Services
- Startup
- Scheduled Tasks
- Background Processes

目标：

发现软件伸出的“手”。

---

# 十、长期扩展方向

未来增加：

- 更多软件指纹
- 更多流氓组件规则
- 自动维护报告
- 企业级设备管理
- AI辅助分析

但是执行链始终保持人工确认。

---

# 十一、最终目标

让普通家庭电脑达到：

- 软件干净
- 后台少
- 广告少
- 启动快
- 功能不丢
- 风险可控

而不是破坏用户环境。
