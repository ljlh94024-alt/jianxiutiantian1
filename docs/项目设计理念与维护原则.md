# Windows Clean Agent

# 项目设计理念与维护原则

版本：V2.0

---

# 一、项目定位

本项目不是：

- 杀毒软件
- 远控软件
- 系统管家
- 一键优化工具
- 自动清理工具

本项目定位：

> 面向普通家庭 Windows 电脑的一次性整理维护系统。

目标不是破坏环境，而是在用户授权后，帮助维护人员快速发现电脑中的无价值软件、推广组件、后台驻留程序，并恢复一个干净、稳定、易用的电脑环境。

核心场景：

维护人员通过网页查看客户电脑状态，人工判断后生成任务，客户电脑 Agent 按安全规则执行，并返回完整结果。

---

# 二、核心设计思想

## 1. 人负责决策，程序负责执行

系统不能替用户决定电脑应该变成什么样。

禁止：

- AI自动删除软件
- AI自动判断用户习惯
- 自动修改重要系统配置
- 自动替换用户常用软件

正确流程：

```
扫描
↓
分析
↓
网页展示
↓
人工确认
↓
安全执行
↓
验证结果
```

---

## 2. 目标不是删除最多软件

错误目标：

删除越多越干净。

正确目标：

- 保留用户需要的软件
- 保留用户习惯
- 删除明显无价值软件
- 去除广告和推广组件
- 降低后台负担
- 提升电脑使用体验

---

# 三、核心维护理念：软件主体与附属组件分离

很多家庭电脑问题不是软件主体，而是软件伸出来的附属功能。

例如：

一个软件可能包含：

- 主程序
- 更新程序
- 推广程序
- 广告服务
- 壁纸模块
- 新闻模块
- 推荐模块
- 后台助手

维护重点不是简单卸载软件，而是识别并处理无价值组件。

重点对象：

- Windows服务
- 启动项
- 计划任务
- 后台进程
- 推广助手
- 广告模块

---

# 四、保护原则

## 第一原则：保护用户数据

永远禁止误处理：

- 用户文档
- 图片
- 视频
- 浏览器收藏夹
- 浏览器密码
- 用户词库

---

## 第二原则：保护常用软件

默认保护：

办公：

- WPS
- Microsoft Office
- LibreOffice

通讯：

- 微信
- QQ
- 企业微信
- 钉钉
- 飞书

浏览器：

- Edge
- Chrome
- Firefox
- 用户主要浏览器

输入法：

- 输入法主体
- 用户词库
- 默认设置

---

# 五、软件处理策略

## 1. 替换优先

不要先删除，再让用户寻找替代品。

流程：

旧软件确认
↓
安装替代软件
↓
功能验证
↓
删除旧软件

示例：

2345看图王
↓
ImageGlass

360压缩
↓
7-Zip

广告播放器
↓
VLC

---

## 2. 明确处理名单

重点：

- 鲁大师生态
- 壁纸屏保软件
- 桌面美化软件
- 2345推广生态
- 360非核心推广组件

原则：

不是因为品牌删除，而是因为明确属于无必要维护内容。

---

# 六、输入法特殊原则

输入法不是普通软件。

原因：

- 用户依赖高
- 词库重要
- 使用习惯强

禁止：

- 删除输入法主体
- 删除用户词库
- 修改默认输入法

允许：

- 清理广告弹窗
- 禁止推广启动项
- 关闭资讯模块
- 清理推荐组件
- 清理推广缓存

目标：

保留输入能力，去除骚扰行为。

---

# 七、后台组件维护理念

系统必须关注“软件伸出来的手”。

重点检查：

## 服务

检查：

- 服务名称
- 文件路径
- 发布商
- 启动方式

---

## 启动项

检查：

- 开机启动程序
- 用户启动目录
- 注册表启动项

---

## 计划任务

检查：

- 定时更新
- 推广任务
- 弹窗任务

---

## 后台进程

检查：

- 路径
- 发布商
- 文件签名

---

# 八、规则系统设计

禁止：

只根据软件名称删除。

必须综合判断：

- 软件名称
- 软件家族
- 发布商
- 安装路径
- 服务名称
- 启动项名称
- 计划任务名称
- 文件信息

降低误伤。

---

# 九、规则分类

规则库：

```
protected

保护对象

replace

替代软件

remove

明确处理软件

component_behavior

后台组件行为
```

---

# 十、安全执行链

任何真实操作必须经过：

```
任务创建
↓
目标确认
↓
权限验证
↓
规则验证
↓
安全执行器
↓
结果验证
↓
日志记录
```

禁止：

- 任意Shell
- 任意命令执行
- 隐藏运行
- 绕过权限
- 未授权删除

---

# 十一、执行可审计原则

所有操作必须记录：

- 谁发起
- 哪台电脑
- 什么操作
- 为什么操作
- 执行结果
- 错误原因

出现问题可以回溯。

---

# 十二、AI使用原则

AI定位：

辅助工具。

允许：

- 分析报告
- 生成建议
- 总结日志
- 帮助维护人员判断

禁止：

- AI直接删除软件
- AI直接修改电脑
- AI绕过规则执行

---

# 十三、长期发展方向

未来扩展：

- 更多软件生态规则
- 更多后台组件识别
- 自动维护报告
- 批量客户管理
- 企业设备管理
- AI辅助分析

但是核心原则不改变：

> 人决定，程序执行，规则约束，结果可追溯。

---

# 十四、最终目标

让普通家庭电脑达到：

- 软件干净
- 后台少
- 广告少
- 启动快
- 功能完整
- 操作简单
- 风险可控

不是把电脑变成空白系统，而是恢复一个普通用户真正需要的电脑环境。
