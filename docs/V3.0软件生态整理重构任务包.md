# Windows Clean Agent V3.0 软件生态整理重构任务包

## 项目定位

从单纯 Windows 清理工具升级为一次性家庭电脑软件生态整理 Agent。

目标：

- 使用 Kilo Code + MCP 获得本机操作能力
- 扫描家庭 Windows 电脑环境
- 分析软件用途
- 迁移不需要的软件生态
- 保留用户需要的功能
- 最后清除临时清理工具

## 核心原则

1. 不盲目删除
2. 删除前先确认功能替代
3. 半自动项目只整理，不删除
4. 用户数据优先保护
5. 所有危险操作经过 Safety Gate

## 总流程

```
Computer Scan
↓
Software Inventory
↓
Software Fingerprint
↓
Function Analysis
↓
Replacement Check
↓
Migration Plan
↓
Safety Gate
↓
Execute
↓
Verify
↓
Remove Temporary Tools
```

## 软件生态迁移模块

### 360

处理：

- 360安全卫士
- 360杀毒
- 360浏览器
- 360压缩
- 360看图
- 360壁纸
- 360驱动相关组件

原则：

先保证功能，再卸载组件。

### 2345

处理：

- 2345浏览器
- 2345好压
- 2345看图王
- 2345相关推广组件

重点：

看图功能必须先找到替代方案。

## 浏览器整理

检查：

- 默认浏览器
- 收藏夹
- 登录状态
- 用户配置

不删除常用浏览器，只拆除附加推广组件。

## 替代软件数据库

建立：

```
replacement_database.json
```

记录：

- 原软件
- 功能
- 推荐替代
- 风险等级
- 是否自动迁移

## MCP能力要求

需要：

- 文件扫描
- 软件列表读取
- 文件移动
- 注册表读取
- 命令执行
- 报告生成

## 完成标准

- 家庭电脑可安全整理
- 不破坏常用功能
- 生成中文报告
- 清理完成后删除自身临时工具
