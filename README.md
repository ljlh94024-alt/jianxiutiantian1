# Windows Clean Agent

基于 Kilo Code + MCP 的一次性 Windows 家庭电脑分析与整理 Agent。

## 项目目标

- 扫描 Windows 家庭电脑
- 建立电脑画像
- 分析磁盘、软件、启动项
- 安全整理垃圾和旧安装包
- 输出中文报告

## 核心原则

- AI 负责规划
- MCP 提供操作能力
- 规则引擎控制风险
- 成熟工具负责执行

## 开发路线

1. 基础框架
2. MCP 接入
3. Inventory 扫描
4. Computer Profile
5. Rule Engine
6. Planner
7. Safety Gate
8. Dry Run
9. Executor
10. 工具适配
11. 报告系统
12. 测试
